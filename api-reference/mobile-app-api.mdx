**Base URL:** `https://app.imploy.com.au/api/v1`  
**Auth:** `Authorization: Bearer <sanctum-token>`

## Appointments / Shifts

| Method | Endpoint | Description | Units |
| --- | --- | --- | --- |
| GET | `/appointments` | This worker's upcoming appointments | 2 |
| GET | `/monthwiseshift` | Appointments grouped by month | 2 |
| GET | `/weeklyhours` | Hours worked this week | 2 |
| GET | `/shift-pool` | Available unassigned shifts | 2 |
| POST | `/acceptshift` | Accept a shift from pool | 8 |
| POST | `/declineshift` | Decline a shift | 8 |
| POST | `/appointment/checkin` | Clock in to a shift | 8 |
| POST | `/appointment/checkout` | **Clock out: AI caution analysis, billable entry, and budget deduction** | 60 |
| POST | `/appointment/shiftnote` | **Submit shift note with AI caution analysis** | 60 |

#### Checkout payload

```json
{
  "appointment_id": 101,
  "shift_notes": "Client was in good spirits. Medication administered on time. No concerns.",
  "time": "2026-07-07T11:05:00",
  "kms_travelled": 12.4
}
```

<Info>
Checkout records the time, saves notes, runs Azure OpenAI GPT-5.4 safety analysis, creates `ShiftCaution` records for severity `>= 5`, notifies care managers, creates billable entries, applies budget deductions, and can auto-create travel claims when consecutive appointments are detected.
</Info>
