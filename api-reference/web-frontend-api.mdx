#### Import billing detail

```
POST /settings/import
 5 rows  ->  5 x 30 = 150 cells  ->  150 units   =  $1.125
10 rows  -> 10 x 30 = 300 cells  ->  300 units   =  $2.250
50 rows  -> 50 x 30 = 1,500 cells -> 1,500 units =  $11.25
```
