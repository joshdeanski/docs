**Base URL:** `https://app.imploy.com.au/api/enterprise/v1`  
**Auth:** `X-API-Key: impl_live_...`

## Clients

| Method | Endpoint | Description | Units |
| --- | --- | --- | --- |
| GET | `/clients` | List clients | 2 |
| GET | `/clients/{id}` | Get client | 2 |
| GET | `/clients/{id}/budget` | Get client budget | 2 |
| GET | `/clients/{id}/overview` | Get client overview | 2 |
| POST | `/clients/bulk-create` | Bulk create clients (max 500) | max(25,N) |

#### Bulk create clients payload

```json
{
  "items": [
    {
      "first_name": "Jane",
      "last_name": "Smith",
      "client_type": "NDIS",
      "language": "English",
      "status": "Active",
      "business_id": 1,
      "date_of_birth": "1985-03-15",
      "gender": "Female",
      "address": "12 Example St, Sydney NSW 2000"
    }
  ]
}
```
