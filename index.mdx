Imploy Platform is a multi-tenant healthcare management platform for Australian NDIS, HCP, and aged care providers. This documentation covers the current API surface, authentication model, usage billing, and the endpoint groups documented in the source reference.

## API surfaces

| Surface | Base URL | Auth Method | Primary Consumers |
| --- | --- | --- | --- |
| **Enterprise** | `/api/enterprise/v1/` | X-API-Key | Third-party integrations, automation |
| **Mobile App** | `/api/v1/` | Sanctum Bearer | iOS / Android staff app |
| **Web Frontend** | `/api/web/v1/` | Sanctum Bearer | React SPA (browser) |

## Architecture

- **Multi-tenancy:** Each organisation has its own MySQL database. The API layer validates your key, identifies your organisation, and switches the active database connection per request.
- **Billing pipeline:** Every successful response triggers a usage event via `QueueUsageEvent` middleware. It fires after the response is sent, so there is no added request latency.
- **AI caution pipeline:** Every shift checkout and shift note submission sends notes to Azure OpenAI GPT-5.4. Severity `>= 5` triggers `ShiftCaution` records and care manager notifications.
