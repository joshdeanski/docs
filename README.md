# Imploy Platform API Docs

Mintlify documentation project for the Imploy platform API.

## Local development

Install the Mint CLI if needed:

```bash
npm i -g mint
```

Run the docs locally from the project root:

```bash
mint dev
```

## Validation

- Broken links: `mint broken-links`
- Accessibility checks: `mint a11y`

## Content source

The current documentation set was migrated from `imploy-api-documentation.html` and reorganised into Mintlify MDX pages.
